# Tipografías locales

Fuentes descargadas para que ROLLAPP funcione sin conexión y para comparar cinco direcciones visuales. Todas se distribuyen bajo SIL Open Font License 1.1 mediante Google Fonts.

- Cinzel Decorative: https://fonts.google.com/specimen/Cinzel+Decorative
- Cormorant SC: https://fonts.google.com/specimen/Cormorant+SC
- MedievalSharp: https://fonts.google.com/specimen/MedievalSharp
- Almendra: https://fonts.google.com/specimen/Almendra
- Uncial Antiqua: https://fonts.google.com/specimen/Uncial+Antiqua
- EB Garamond (texto narrativo): https://fonts.google.com/specimen/EB+Garamond
- Licencia: https://openfontlicense.org/

No se usa ninguna CDN en ejecución. Los ficheros están en `assets/fonts`.
